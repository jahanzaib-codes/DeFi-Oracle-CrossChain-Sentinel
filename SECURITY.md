# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

1. **Responsible Disclosure**: Do not publish security vulnerabilities or exploit payloads in public GitHub issues.
2. **Contact**: Open a confidential GitHub Security Advisory or message the maintainer via Telegram at `@JanzebBlockdev`.
3. **Response SLA**: Vulnerability submissions are triaged within 24 hours.
